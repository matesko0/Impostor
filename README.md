# Impostor

Vlajka 01: Nepoužité adresy pro subnet s počítačiPro 129 počítačů potřebujeme blok o velikosti 256 adres ($2^8$).Celkem adres: 256Rezervované: 2 (síť a broadcast)Použitelné: 254Výpočet: $254 - 129 = 125$Správná odpověď: 125Vlajka 02: Adresa sítě (Tiskárny)Jelikož subnet s počítači zabral celý rozsah 192.168.0.0 až 192.168.0.255, další volná adresa, kde můžeme začít segment pro tiskárny, je hned následující.Správná odpověď: 192.168.1.0Vlajka 03: Broadcast adresa (IP kamery)Segment pro kamery začíná na 192.168.1.64 a má velikost 32 adres. Rozsah je tedy 192.168.1.64 až 192.168.1.95. Poslední adresa v bloku je vždy broadcast.Správná odpověď: 192.168.1.95Vlajka 04: Maska sítě (Počítače)Pro 129 zařízení potřebujeme prefix /24. To v dekadickém zápisu znamená, že první tři oktety jsou „plné“ (samé jedničky v binární soustavě).Správná odpověď: 255.255.255.0Vlajka 05: Prefix sítě (IP kamery)Pro 25 zařízení potřebujeme blok o velikosti 32 adres ($2^5$). Prefix vypočítáme jako $32 - 5 = 27$.Správná odpověď: /27
